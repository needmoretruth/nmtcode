## 0.0.1 — 2026-09-29

The first release.

### Added

- Make black-and-white NMT Code symbols from text, a URL or a file, as PNG or SVG.
- Read symbols from camera photos, screenshots and image files (PNG, JPEG).
- Choose the error-correction level (0–3), the size in modules, the module size and the DPI.
- Pick the shortest of six codecs for the content, including Hangul packing and brotli.
- Add a QR Code that links to this repository beside the symbol with `--qr`; printed codes have it.
- A web page that makes codes and reads them with the camera or from an image file, in the browser.
- Binaries for Linux, macOS and Windows, and a Rust library.
- Version 0.2 of the format specification, under CC BY 4.0.
